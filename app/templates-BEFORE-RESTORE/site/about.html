About the project

ECO-SENTINEL is an AI-assisted vegetation loss detection and alerting system built to compare satellite imagery of a forest region across two time periods, identify where vegetation has genuinely been lost, and route that information to the right people.

The problem

Forest loss is often noticed too late — after it's already visible on the ground, long after it started. Satellite imagery makes change visible far earlier, but manually comparing images across time, distinguishing real loss from seasonal variation, and figuring out who's responsible for follow-up is slow and error-prone.

The approach

The system computes NDVI (a standard vegetation-health measure derived from satellite bands) for two years, finds where it dropped beyond normal fluctuation, converts those areas into mapped polygons with real hectare sizes and severity levels, and checks each one against real land-cover data to determine if it's inside protected forest or not. Inside-forest loss gets a full evidence package and a tamper-evident blockchain record for the Forest Department. Outside-forest loss goes to a separate awareness view for NGOs.

Study area

Coastal Karnataka, India (Dakshina Kannada / Mangaluru region), using real Sentinel-2 imagery comparing 2023 and 2025.

Tech stack

Python, Flask, rasterio, GeoPandas, Shapely, SQLite, Leaflet.js, Bootstrap. Satellite processing via Sentinel-2 Level-2A imagery. Blockchain integrity via a SHA-256 chained ledger (a real, verifiable hash chain — not a live public network).

What this system does and doesn't do

To be precise about scope: detection here is threshold-based (an NDVI drop past a defined cutoff), not a trained machine-learning classifier. The blockchain layer is a real, independently-verifiable SHA-256 hash chain running locally, not a deployment on a public network like Ethereum. There's no timber supply-chain or permit-tracking component — this system's job ends at detecting, classifying, and alerting on vegetation loss.
